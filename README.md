## 서비스 개요

스스로 습관, 공부시간을 관리함

## 기능

### 습관 관리

1. 일일 / 주간습관을 추가하고,
2. 어떤 습관을 지켰는지 / 못지켰는지 매일 체크하면
3. 어제 지키지 못한 습관을 볼 수 있음.

### 공부시간 관리

1. 공부한 시간 / 기상 및 수면시각 / 패배한 원인을 매일 기록하면,
2. 기록과 **통계**를 **달력**과 **표** 형태로 제공함.
3. 이를 통해 좋은 / 나쁜 **패턴**을 스스로 발견하고 고칠 수 있도록 함.

## 대상

1. 습관을 관리하고싶은 **모든 사람**
2. 학습을 하는 모든 사람. 특히 **학생**, 공부하는 **직장인**
